# Knowledge Base Documentation Index

- `INGESTION.md` — canonical/raw Git/document index build behavior.
- `SOURCE_HIERARCHY.md` — source authority and retrieval order.
- `VENDOR_DOCUMENT_INGESTION.md` — private vendor manual indexing rules.
- `PROMOTION_POLICY.md` — rules for promoting evidence into canonical knowledge.

Source registries live in `sources/`. Canonical reviewed records live in `knowledge/`. Generated SQLite/search indexes are derived artifacts and are not the source of truth.
